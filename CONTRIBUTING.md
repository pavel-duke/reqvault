# Как помочь проекту

Спасибо за интерес к ReqVault. Для исправления ошибки сначала создайте issue с коротким примером воспроизведения. Небольшие и очевидные правки можно сразу отправлять pull request.

## Локальная разработка

1. Установите Node.js 22.19+, Rust stable и зависимости Tauri 2 для своей ОС.
2. Выполните `npm ci`.
3. Запустите приложение: `npm run tauri dev`.
4. Создайте отдельную ветку от `main`.

Перед pull request выполните:

```bash
npm run lint
npm run typecheck
npm test
npm run build
cd src-tauri
cargo fmt --check
cargo clippy -- -D warnings
cargo test
cargo check
```

## Требования к изменениям

- Не добавляйте реальные токены, пароли, cookie, приватные URL и дампы ответов.
- Для нового поведения добавляйте тесты.
- Не меняйте `format_version` без описания миграции.
- Пользовательские ошибки должны быть понятными и не содержать секретов.
- Не записывайте тело запроса, заголовки авторизации и значения секретов в логи.
- Обновляйте README и CHANGELOG, если меняется поведение пользователя.

Коммиты желательно делать небольшими и называть по сути изменения. В pull request опишите проблему, решение и способ проверки.
