# Политика безопасности

## Поддерживаемые версии

Пока проект находится до версии 1.0, исправления безопасности выпускаются только для последней опубликованной версии.

## Как сообщить об уязвимости

Не публикуйте уязвимость в обычном issue. Используйте приватный отчёт GitHub Security Advisories в репозитории ReqVault: вкладка **Security → Advisories → Report a vulnerability**.

В отчёте укажите:

- версию ReqVault и операционную систему;
- способ воспроизведения;
- возможное влияние;
- минимальный пример без реальных секретов;
- известный способ временно снизить риск.

Не прикладывайте настоящие токены, пароли, cookie или содержимое чужих workspace. Получение ответа может занять до 7 дней. Срок исправления зависит от серьёзности и сложности проблемы.

Границы защиты и принятые решения описаны в [`docs/threat-model.md`](docs/threat-model.md).
