# UX-проверка ReqVault 1.0

Основные сценарии пройдены на production-сборке Windows с реальным YAML-workspace и локальным HTTP API.

| Сценарий | Результат | Что проверено |
| --- | --- | --- |
| Первый запуск | пройден | назначение продукта понятно без документации, основные действия видны сразу |
| Создание и открытие | пройден | системный выбор папки, обзор workspace, восстановление последней папки |
| Импорт | пройден тестами | Postman, OpenAPI JSON/YAML, внешний локальный `$ref`, cURL и bundle |
| Отправка | пройден | окружение, query, заголовки, HTTP status, timing и JSON preview |
| Проверки | пройден | status, header, JSON path и response time в UI, YAML и CLI |
| Секреты | пройден тестами | ссылка Secret Vault, запрет открытого credential, безопасный draft/export |
| Диагностика | пройден | сводка, фильтры, понятное исправление и отсутствие чтения значения секрета |
| Клавиатура | пройден | `Ctrl+K`, `Alt+N`, `Ctrl+S`, `Ctrl+Enter`, Escape и focus trap |
| Темы | пройден | светлая и тёмная темы, ключевые состояния и focus ring |
| Большой workspace | пройден тестом | 1000 YAML-запросов открываются в стабильном порядке |

## Изменения по результатам

- глобальные инструменты вынесены из дерева запросов в постоянную навигационную панель;
- строка отправки получила отдельный контейнер и видимую подсказку `Ctrl+Enter`;
- добавлен статус «Сохранено / Не сохранено» рядом с типом запроса;
- пустой workspace показывает создание, импорт, runner и горячие клавиши;
- диагностика открывается из любого места и оставляет контекст запроса на фоне;
- response time assertion переведён на переносимый YAML-тип `u64`.

Для 1.1 остаются запланированы вкладки запросов, command palette и виртуализация дерева. Они не включены в 1.0 как незавершённые функции.
