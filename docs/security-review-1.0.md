# Проверка безопасности 1.0

Проверка выполнена перед релизом 1.0.0 и охватывает разрешения desktop-приложения, зависимости и основные пути утечки секретов.

## Разрешения Tauri

Главное окно получает только:

- стандартные безопасные команды Tauri;
- запись текста в clipboard для безопасного cURL;
- системные диалоги открытия и сохранения файлов.

Доступ к shell, выполнению команд, произвольному HTTP из frontend и чтению clipboard не выдан. HTTP, импорт, файловая запись и Secret Vault остаются в Rust-командах с проверкой входных данных.

## Границы данных

- credential в YAML разрешены только как точная ссылка `{{secret:NAME}}`;
- черновик перед локальным сохранением очищается от credential и чувствительных полей;
- safe cURL, HAR, bundle и диагностический отчёт не содержат значений Secret Vault;
- история выключена по умолчанию и хранится вне workspace;
- HTML-ответ открывается в sandboxed iframe;
- размер импортируемого bundle и preview ответа ограничен;
- пути workspace проверяются на выход из корневого каталога;
- запись выполняется через временный файл, flush и atomic replace.

## Проверки перед релизом

```bash
npm audit --omit=dev
npm run lint
npm test
cargo clippy --locked -- -D warnings
cargo test --locked
```

Результаты конкретного прогона записываются в release notes. Коммерческий сертификат подписи кода в проект не входит; поэтому Windows-инсталляторы могут показывать SmartScreen.

На контрольном прогоне 13 августа 2026 года `npm audit` для production и полного дерева зависимостей вернул `0 vulnerabilities`. Дубли Rust-зависимостей просмотрены через `cargo tree -d`: они приходят из Tauri и его платформенных библиотек, прямых лишних runtime-зависимостей не найдено.
