# Roadmap ReqVault

Roadmap задаёт направление, но не заменяет проверку качества. Версия выходит только после тестов, сборки и обновления документации.

## 0.3.0 — переносимость и защита

- [x] OAuth refresh token и повтор после `401`;
- [x] импорт cURL;
- [x] локальные внешние `$ref` OpenAPI;
- [x] экспорт и импорт workspace bundle;
- [x] Production Guard.

## 0.4.0 — автоматические проверки

- [x] проверки статуса, заголовков и JSON-ответа;
- [x] последовательный запуск коллекции;
- [x] CLI с exit code для CI;
- [x] машиночитаемый JSON-отчёт.

## 0.5.0 — GraphQL

- [x] отдельный редактор query и variables;
- [x] GraphQL body без ручной сборки JSON;
- [x] удобное отображение GraphQL errors.

## 0.6.0 — потоки и постоянные соединения

- [x] WebSocket-клиент;
- [x] Server-Sent Events;
- [x] журнал сообщений с фильтрацией.

## 0.7.0 — сессии и авторизация

- [x] изолированный cookie jar на уровне workspace;
- [x] просмотр, поиск и удаление cookie без записи чувствительных значений в YAML;
- [x] автоматическая обработка `Set-Cookie` и отправка подходящих cookie;
- [x] Digest Auth с безопасным хранением пароля;
- [x] AWS Signature V4 для основных AWS API;
- [x] очистка сессии при закрытии workspace и тесты изоляции.

## 0.8.0 — анализ и экспорт ответов

- [ ] сравнение двух ответов: status, headers и структурный JSON diff;
- [ ] экспорт тела, полного ответа и безопасного HAR;
- [ ] поиск и фильтры по запросам, окружениям и истории;
- [ ] сохранение ответа как fixture без credential;
- [ ] просмотр изображений, HTML и бинарных метаданных;
- [ ] лимиты больших ответов и предупреждение о расходе памяти.

## 0.9.0 — надёжность workspace

- [ ] диагностика структуры, YAML, ссылок, файлов и секретов;
- [ ] автоматические резервные копии перед изменениями формата;
- [ ] проверяемые миграции с preview и откатом;
- [ ] безопасная запись через временный файл и atomic replace;
- [ ] обнаружение изменений из внешнего редактора;
- [ ] восстановление последней сессии и несохранённых черновиков;
- [ ] полная клавиатурная навигация и базовый аудит доступности.

## 1.0.0 — стабильный продукт и новый интерфейс

- [ ] миграционные тесты со всеми версиями 0.1–0.9;

- [ ] собственная дизайн-система: сетка, типографика, цвета, иконки, состояния, формы, таблицы и модальные окна;
- [ ] новый трёхуровневый layout для больших API-проектов: навигация, рабочая область и контекст результата;
- [ ] быстрый редактор запроса с понятной визуальной иерархией, компактным режимом и адаптацией под небольшие экраны;
- [ ] продуманные loading, empty, error, success и offline-состояния без резких скачков интерфейса;

- [ ] реальные скриншоты готового приложения для README: аккуратный кадр, фокус на ключевых возможностях, без декоративных мокапов;
- [ ] документация установки, безопасности, CLI, CI и типовых сценариев;
- [ ] onboarding, примеры workspace и встроенные подсказки;
