# Roadmap ReqVault

Roadmap задаёт направление, но не заменяет проверку качества. Версия выходит только после тестов, сборки и обновления документации.

## 0.3.0 — переносимость и защита

- [x] OAuth refresh token и повтор после `401`;
- [x] импорт cURL;
- [x] локальные внешние `$ref` OpenAPI;
- [x] экспорт и импорт workspace bundle;
- [x] Production Guard.

## 0.4.0 — автоматические проверки

- [ ] проверки статуса, заголовков и JSON-ответа;
- [ ] последовательный запуск коллекции;
- [ ] CLI с exit code для CI;
- [ ] машиночитаемый JSON-отчёт.

## 0.5.0 — GraphQL

- [ ] отдельный редактор query и variables;
- [ ] GraphQL body без ручной сборки JSON;
- [ ] удобное отображение GraphQL errors.

## 0.6.0 — потоки и постоянные соединения

- [ ] WebSocket-клиент;
- [ ] Server-Sent Events;
- [ ] журнал сообщений с фильтрацией.

## 0.7.0 — сессии

- [ ] cookie jar на уровне workspace;
- [ ] управление cookie без записи секретных значений в YAML;
- [ ] дополнительные схемы авторизации.

## 0.8.0 — анализ ответов

- [ ] сравнение двух ответов;
- [ ] экспорт ответа в файл;
- [ ] поиск по истории и workspace.

## 0.9.0 — надёжность данных

- [ ] диагностика workspace;
- [ ] резервные копии перед изменением формата;
- [ ] проверяемые миграции;
- [ ] полировка доступности и клавиатурной навигации.

## 1.0.0 — стабильный релиз

- [ ] зафиксированный формат workspace v1;
- [ ] полная документация основных сценариев;
- [ ] проверка обновления с предыдущих версий;
- [ ] стабильные установщики и финальный аудит безопасности.
