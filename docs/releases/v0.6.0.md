ReqVault 0.6.0 добавляет работу с долгоживущими соединениями.

- WebSocket с отправкой текстовых сообщений;
- Server-Sent Events с именованными и многострочными событиями;
- URL и заголовки с переменными окружения и Secret Vault;
- журнал последних 1000 событий;
- фильтр по типу и содержимому события;
- проверка хоста и защищённого протокола через Production Guard.

Журнал потоков хранится только в памяти окна. Значения известных секретов маскируются в Rust до отображения.

> Установщики и CLI пока не подписаны цифровой подписью. Windows SmartScreen может показать предупреждение.
