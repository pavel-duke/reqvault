ReqVault 0.5.0 добавляет отдельный режим работы с GraphQL.

- query, variables и operation name редактируются отдельно;
- variables проверяются как JSON-объект до отправки;
- стандартный GraphQL payload формируется автоматически;
- GraphQL-команды cURL распознаются при импорте;
- массив `errors` показывается отдельно от полного JSON-ответа.

Переменные окружения и Secret Vault работают в GraphQL так же, как в остальных типах запросов.

> Установщики и CLI пока не подписаны цифровой подписью. Windows SmartScreen может показать предупреждение.
