ReqVault 0.3.0 упрощает перенос существующих запросов и добавляет защиту от случайной отправки в production.

Что изменилось:

- команды cURL можно вставлять прямо в приложение;
- OAuth access token обновляется по refresh token, запрос после `401` повторяется один раз;
- OpenAPI импортирует локальные внешние `$ref`;
- workspace экспортируется в один `.reqvault.json` файл без секретов и истории;
- Production Guard ограничивает протокол, хосты и опасные HTTP-методы.

Credential из cURL не сохраняются открытым текстом. При импорте нового workspace создаётся новый UUID, а секреты добавляются отдельно.

> Установщики пока не подписаны цифровой подписью. Windows SmartScreen может показать предупреждение.
