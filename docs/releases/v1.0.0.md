ReqVault 1.0.0 — первый стабильный релиз проекта.

### Главное

- полностью новый интерфейс с трёхуровневой навигацией и собственной дизайн-системой;
- быстрый редактор запроса, понятный статус сохранения и контекст результата;
- новый первый запуск, обзор workspace и встроенные подсказки;
- стабильный контракт workspace v1 и миграции с backup/rollback;
- совместимость с workspace из версий 0.1–0.9 подтверждена тестами;
- реальные скриншоты production-сборки и обновлённая документация;
- сборки Windows, подготовленный pipeline macOS/Linux и отдельный CLI;
- 61 Rust-тест и 14 frontend-тестов;
- `npm audit`: 0 известных уязвимостей.

### Исправления

- response-time assertion теперь корректно сохраняется и читается из YAML;
- большие workspace открываются в стабильном порядке; добавлен тест на 1000 запросов;
- улучшены состояния фокуса, reduced motion, адаптивная сетка и семантика вкладок.
