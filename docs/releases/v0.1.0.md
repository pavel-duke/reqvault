Первая рабочая версия ReqVault.

Сейчас можно создавать локальные workspace, сохранять REST-запросы, использовать окружения и хранить токены отдельно через системное хранилище ОС.

Также добавлены безопасное копирование cURL и базовые предупреждения для потенциально опасных запросов.

Проект пока ранний, поэтому формат файлов и интерфейс ещё могут меняться.
