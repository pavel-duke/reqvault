Вторая рабочая версия ReqVault.

Добавлены OAuth 2.0 с PKCE и Client Credentials, multipart, proxy, custom CA и mTLS. Коллекции можно импортировать из Postman и OpenAPI.

История ответов по-прежнему не включается автоматически. Её можно отдельно включить для workspace и задать лимит записей.

Credential из импорта и полей авторизации не сохраняются открытым текстом: для них используется Secret Vault операционной системы.
