ReqVault 0.4.0 добавляет воспроизводимые API-проверки и запуск коллекций.

В запросе можно проверить:

- HTTP status;
- наличие или значение заголовка;
- значение по JSON path;
- фрагмент тела;
- максимальное время ответа.

Коллекции запускаются из интерфейса или через `reqvault-cli`. CLI возвращает отдельные exit code для успешного прогона, упавших проверок и ошибки запуска. При необходимости он записывает компактный JSON-отчёт без тел ответов и значений секретов.

> Установщики и CLI пока не подписаны цифровой подписью. Windows SmartScreen может показать предупреждение.
