ReqVault 1.1.0 — релиз для повседневной работы с большими API-проектами.

### Что нового

- command palette по `Ctrl+K` / `Cmd+K` с поиском запросов и быстрыми действиями;
- вкладки с признаком несохранённых изменений и восстановлением после перезапуска;
- локальные списки закреплённых и недавно открытых запросов;
- поиск по имени, URL, методу, пути коллекции и безопасным именам заголовков;
- массовое перемещение, переименование и дублирование без перезаписи файлов;
- виртуализированное дерево для workspace с тысячами запросов;
- Dependabot, CodeQL, gitleaks, RustSec, SPDX SBOM и provenance attestations в CI.

### Безопасность

- чувствительные заголовки удаляются при redirect на другой scheme, host или port;
- AWS Signature V4 блокирует междоменный redirect с подписью исходного запроса;
- Production Guard проверяет private, loopback, link-local и cloud metadata адреса;
- DNS-проверки защищают от hostname, который разрешается во внутренний адрес;
- временные значения токенов, паролей, request body и PEM identity очищаются из памяти там, где это поддерживается;
- mTLS предупреждает о незашифрованном PEM-ключе без показа его содержимого или пути;
- вкладки, поиск и восстановление черновика не сохраняют credential и ответы.

### Исправления

- повторный запуск приложения возвращает фокус существующему окну;
- массовые операции заранее проверяют пути, не перезаписывают файлы и откатывают перемещение при ошибке;
- redirect ограничен десятью переходами и проверяется Production Guard на каждом шаге;
- восстановление вкладок не ломает старый формат workspace v1.

### Проверки

- 69 Rust-тестов и 20 frontend-тестов;
- ESLint, TypeScript, Rustfmt, Clippy и production build прошли без ошибок;
- `npm audit`: 0 известных уязвимостей;
- RustSec: блокирующих advisory нет; информационные предупреждения GTK3-ветки Tauri остаются видимыми;
- gitleaks: история Git проверена, утечек не найдено.
