# Архитектура ReqVault

ReqVault — desktop-приложение Tauri 2. Интерфейс работает в системном WebView, а операции с файлами, сетью и секретами выполняет Rust-часть через ограниченный набор Tauri-команд.

```text
React + TypeScript
  │ invoke(command)
  ▼
Tauri commands
  ├─ workspace ── YAML-файлы в выбранной папке
  ├─ http ─────── reqwest + rustls
  ├─ secrets ──── хранилище учётных данных ОС
  └─ security ─── анализ запроса и безопасный cURL
```

## Frontend

Код находится в `src/`.

- `App.tsx` хранит состояние открытого workspace, выбранного запроса, ответа и темы.
- `api.ts` — типизированные вызовы Rust-команд.
- `components/` — редактор, боковая панель, ответы, окружения, секреты и Security Lens.
- `types.ts` повторяет сериализуемые структуры Rust.

Frontend не читает workspace напрямую и не получает сохранённые значения секретов. Разрешения Tauri дают окну только выбор папки и запись текста в буфер обмена.

## Rust

Код находится в `src-tauri/src/`.

- `commands/` — тонкий IPC-слой без бизнес-логики;
- `workspace/` — создание, чтение и безопасная запись YAML внутри workspace;
- `http/` — проверка данных, подстановка переменных и секретов, отправка запроса;
- `secrets/` — работа с Windows Credential Manager, macOS Keychain или Linux Secret Service;
- `security/` — Security Lens и генерация cURL;
- `variables/` — разбор `{{NAME}}` и `{{secret:NAME}}`;
- `redaction/` — маскирование чувствительных заголовков и известных значений;
- `models/` — общий формат данных.

## Поток отправки запроса

1. Frontend отправляет структуру запроса, выбранное окружение и UUID workspace в Rust.
2. Rust проверяет HTTP-метод, URL, заголовки, JSON, таймаут и настройки редиректов.
3. Переменные окружения подставляются из YAML.
4. Секреты загружаются из системного хранилища только по найденным ссылкам.
5. `reqwest` отправляет запрос через TLS-библиотеку rustls.
6. Чувствительные заголовки и известные значения секретов маскируются до возврата ответа в WebView.
7. Ответ хранится только в памяти состояния React и заменяется следующим ответом.

## Версионирование файлов

Каждый YAML-файл содержит `format_version: 1`. Файл с неизвестной версией не открывается, чтобы приложение не интерпретировало данные неверно. Миграций в версии 0.1.0 нет.

## Проверки

Vitest проверяет преобразования frontend и отображение важных состояний. Rust-тесты проверяют workspace, пути, переменные, redaction, Security Lens, системное хранилище и реальную отправку запросов на локальный тестовый TCP-сервер.
