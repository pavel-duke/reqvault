# Первые 10 минут с ReqVault

## 1. Установка

Для Windows скачайте `.exe` (NSIS) или `.msi` из [последнего релиза](https://github.com/pavel-duke/reqvault/releases/latest). Оба установщика содержат одно и то же приложение.

Установщики пока не подписаны коммерческим сертификатом. Поэтому SmartScreen может показать предупреждение. Сверьте SHA-256 с хешем на странице релиза и устанавливайте файл только из репозитория `pavel-duke/reqvault`.

Сборки macOS и Linux подготавливаются в CI. Пока они не приложены к релизу, используйте запуск из исходников по инструкции в README.

## 2. Первый workspace

1. Нажмите «Создать workspace» и выберите пустую папку.
2. Откройте окружения и задайте `BASE_URL`, например `http://127.0.0.1:3000`.
3. Создайте запрос, выберите метод и укажите `{{BASE_URL}}/health`.
4. Добавьте проверки статуса, заголовка или JSON path во вкладке «Проверки».
5. Нажмите «Отправить» или `Ctrl+Enter`.

Workspace можно сразу добавить в Git: это обычная папка с YAML.

## 3. Секреты

Откройте Secret Vault, добавьте имя `API_TOKEN` и значение. В запросе используйте только ссылку:

```yaml
auth:
  type: bearer
  token: "{{secret:API_TOKEN}}"
```

Значение хранится в Windows Credential Manager, macOS Keychain или Secret Service в Linux. Оно не попадает в YAML, bundle, историю и безопасный HAR.

## 4. Импорт существующего API

Кнопка импорта принимает:

- Postman Collection 2.x;
- OpenAPI 3.x и Swagger 2.0 в JSON/YAML;
- команду cURL;
- переносимый ReqVault bundle.

После импорта откройте «Диагностику». Она покажет отсутствующие переменные, ссылки на Secret Vault, сертификаты и файлы multipart.

## Полезные клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+K` | поиск по workspace |
| `Alt+N` | новый запрос |
| `Ctrl+S` | сохранить запрос |
| `Ctrl+Enter` | отправить запрос |
| `Escape` | закрыть диалог |
