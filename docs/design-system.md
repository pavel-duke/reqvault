# Интерфейс ReqVault 1.0

Дизайн-система построена вокруг работы с большими API-проектами: глобальные инструменты находятся в узкой левой панели, структура проекта — рядом, запрос и результат занимают основную область.

## Основные правила

- шаг сетки — 4 px, основные интервалы — 8/12/16/24 px;
- один акцентный цвет используется для выбранного состояния и главного действия;
- системный шрифт остаётся читаемым без загрузки внешних ресурсов;
- код, URL, размеры и timing показываются моноширинным шрифтом;
- светлая и тёмная темы используют одинаковую иерархию контраста;
- состояние не передаётся только цветом: текст, форма и иконка дублируют смысл;
- все ключевые сценарии доступны с клавиатуры, модальные окна удерживают фокус;
- анимации короткие и отключаются через `prefers-reduced-motion`.

SVG-иконки входят в код приложения и визуально согласованы по сетке 24×24. Интерфейс не зависит от внешнего icon CDN и продолжает работать без сети.
