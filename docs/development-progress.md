# Текущая точка разработки

Файл обновляется перед завершением рабочей сессии и помогает продолжить работу без потери контекста.

## Состояние на 2026-08-13

- Последний готовый к публикации релиз: `0.8.0`.
- GitHub: <https://github.com/pavel-duke/reqvault>.
- Следующий этап: `0.9.0 — надёжность workspace`.
- Roadmap расширен до `3.0.0`.

## Сделано для 0.8.0

- метаданные ответа: Content-Type, вид body и признак обрезанного preview;
- потоковый лимит загрузки ответа 8 МБ;
- Base64-представление бинарных данных и preview изображений/HTML;
- безопасный экспорт body, полного HTTP и HAR;
- сохранение ответа в `fixtures/` без перезаписи существующего файла;
- поиск запросов, URL и окружений в боковой панели;
- модуль структурного diff для status, headers и JSON;
- начат интерфейс действий над ответом.
