# Текущая точка разработки

Файл обновляется перед завершением рабочей сессии и помогает продолжить работу без потери контекста.

## Состояние на 2026-08-14

- Последний опубликованный релиз: `1.0.0`.
- Текущий release candidate: `1.1.0`.
- GitHub: <https://github.com/pavel-duke/reqvault>.
- Следующий этап: `1.2.0 — сценарии и цепочки`.
- Roadmap расширен до `3.0.0`.

## Сделано для 1.1.0

- добавлены command palette, поиск, закреплённые и недавно открытые запросы;
- добавлены вкладки с безопасным восстановлением несохранённых черновиков;
- добавлены массовые файловые операции без перезаписи и виртуализация дерева;
- исправлено поведение повторного запуска и возврат фокуса существующему окну;
- усилена защита redirect, SSRF, временных секретов и mTLS;
- добавлены Dependabot, CodeQL, gitleaks, SBOM, SHA-256 и attestations;
- локально проверены Rust, frontend, зависимости и история Git.

## Следующие действия

1. Собрать, опубликовать и проверить установщик `1.1.0`.
2. Реализовать runtime variables и безопасные операции цепочек для `1.2.0`.
3. Добавить trace, условия, генераторы данных и защитные лимиты.
4. Продолжить последовательные релизы по roadmap до `3.0.0`.

## Внешние ограничения

- Windows-установщики не подписаны: code-signing сертификат отсутствует.
- GitHub Actions могут не запускаться из-за блокировки billing аккаунта GitHub; локальные проверки выполняются перед каждым релизом.
